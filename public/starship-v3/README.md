# 星舰 V3 · 工程级 3D 交付（Vibe Coding 作品集）

用自然语言驱动的 AI 编程（Vibe Coding）从零完成的星舰 V3 全套工程交付：

- **参数化 3D 模型**：真实尺寸 124.4 m / 直径 9.0 m，12 个命名部件，GLB / STL（可 3D 打印）/ OBJ
- **交互式查看器**：全栈 / 助推器 / 飞船三模型切换、一键爆炸图、部件独立开关、照片级 PBR 材质
- **工程图纸**：10 张零件图 + 2 张装配图（总装图 + 爆炸图 + BOM），PNG / SVG
- **维修手册**：18 章自包含 HTML，可直接打印
- **工程资料中心**：入口 `index.html`，左侧导航一键切换 3D / 手册 / 图纸 / 渲染 / 文件

> 本项目为演示交付物：模型尺寸与手册内容为示例数据，不构成真实飞行器维修依据。
